## What changed

0.3.1 修复 OpenAPI 投影到 Thrift/Go 校验标签时遗漏数组元素递归约束的问题。数组元素现在会生成 `dive`，并继续应用元素自身的长度或嵌套对象校验；Go 核心、WASM、测试 fixture 和 backend 固定快照已同步。

## Why it matters

调用方提交数组时，元素级约束会在生成的运行时校验中生效，避免顶层数组结构通过而非法元素进入服务。

## Demo posture / limitations

该版本面向 npm、Go module 和六平台 CLI 的稳定修复发行。Windows/macOS 归档仍未提供操作系统签名或公证；SHA-256 和 npm provenance 用于产物完整性与来源验证。
