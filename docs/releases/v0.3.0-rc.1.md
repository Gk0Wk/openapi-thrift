OpenAPI Thrift 0.3.0-rc.1 将 OpenAPI 校验与 Thrift 转换统一到 Go 核心，同时提供 npm/WASM、Go Module 和原生命令行。它是有接口变更的预发布版本。

- npm：保留 `@sttot/openapi-thrift` 包名，使用前先等待 `initializeOpenApiThrift()`；包内自带预编译 WASM，消费者不需要 Go。安装固定版本：`npm install @sttot/openapi-thrift@0.3.0-rc.1`。
- Go：`go get github.com/Gk0Wk/openapi-thrift@v0.3.0-rc.1`；CLI：`go install github.com/Gk0Wk/openapi-thrift/cmd/openapi-thrift@v0.3.0-rc.1`。
- 无编译器环境：下载对应 Windows/macOS/Linux amd64/arm64 归档，校验 `SHA256SUMS` 后解包运行 `openapi-thrift --version`。归档包含 LICENSE 和来源说明。

旧 npm CLI 与 `openapi-render` 别名已移除。浏览器需要部署 WASM 资源并允许对应 CSP；Node 消费者显式读取导出的 WASM 文件再初始化。包体约 1.45 MB gzip，推荐按需加载；大输入在 Worker 中处理。

原生 CLI 支持 JSON/YAML，转换失败不会破坏既有输出。仍只接受已冻结的 OpenAPI profile，不承诺支持任意 OpenAPI schema；原有 unsupported 情况继续显式失败。

详细安装、版本身份、验证与限制见仓库 `README.md` 和 `docs/distribution.md`。Windows/macOS 二进制未进行 OS 签名或公证。本次发行不代表真实项目已迁移、所有打包器/浏览器已验收或生产环境已部署。
