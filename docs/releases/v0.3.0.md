OpenAPI Thrift 0.3.0 将 OpenAPI 校验与 Thrift 转换统一到 Go 核心，提供 npm/WASM、Go Module 和六平台原生命令行。这是 Go/WASM 迁移的稳定发行，包含相对 0.2.x 的不兼容接口变化；转换核心与已验收的 0.3.0-rc.1 保持一致。

- npm：`npm install @sttot/openapi-thrift@0.3.0`。包名保持不变，包内自带预编译 WASM；使用前等待 `initializeOpenApiThrift()`，消费者不需要 Go。
- Go：`go get github.com/Gk0Wk/openapi-thrift@v0.3.0`；CLI：`go install github.com/Gk0Wk/openapi-thrift/cmd/openapi-thrift@v0.3.0`。
- 无编译器环境：下载 Windows/macOS/Linux amd64/arm64 归档，核对 `SHA256SUMS` 后解包运行 `openapi-thrift --version`。归档包含 LICENSE、版本和源码提交信息。

旧 npm CLI 与 `openapi-render` 别名已移除。浏览器需要部署 WASM 资源并允许对应 CSP；Node 消费者显式读取导出的 WASM 文件再初始化。建议按需加载，大输入在 Worker 中处理。

原生 CLI 支持 JSON/YAML，转换失败不会破坏既有输出。只接受已冻结的 OpenAPI profile，unsupported schema 继续显式失败。npm 稳定通道为 `latest`，Go tag 和所有归档使用同一版本与源提交。

发行使用 GitHub OIDC 与 npm provenance，发布请求禁止自动重发，保留原始 HTTP 失败；读取与安装验证仍有独立门禁。详细安装、版本身份与故障恢复见 `README.md` 和 `docs/distribution.md`。

Windows/macOS 二进制未进行 OS 签名或公证。稳定发行不代表真实项目已迁移、所有浏览器/打包器已验收或生产环境已部署。
